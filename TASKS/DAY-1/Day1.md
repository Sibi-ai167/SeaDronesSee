# SeaDronesSee Maritime Search & Rescue Object Detection

## Dataset

**SeaDronesSee Dataset (SDS Dataset)**

Dataset Link: https://www.kaggle.com/datasets/ubiratanfilho/sds-dataset

The SeaDronesSee dataset is a maritime UAV benchmark designed for search and rescue applications. It contains high-resolution drone imagery with object annotations for swimmers, boats, jetskis, buoys, and life-saving appliances.
